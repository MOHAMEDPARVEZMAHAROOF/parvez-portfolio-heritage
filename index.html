The Manifesto
“AI study tools sound confident even when they're wrong. Students can't tell which claims to trust. So I build systems where grounding is a systems problem — citations validated, not decorative, fallbacks labeled, honest by architecture.”
Parvez Maharoof — engineering notes, 2026

Grounded, not confident

READMEs that disclaim limits. Template modes labeled. No accuracy claims invented.

Shipped, not demoed

Backend, frontend, tests, demo video, docs — a product, every single time.

India-first problems
